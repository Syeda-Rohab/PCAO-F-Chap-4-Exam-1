AI Prompting in 2026: A Crash Course

Chapter Explanation — Roman Urdu (Bohat Bohat Asaan Version)

Shuruaat

Intro:

Zyada tar log AI ko Google jaisa use karte hain — chhota sawal poochte, jawab dekh kar aage barh jate hain. Ye chhoti baaton ke liye theek hai, asal kaam ke liye nahi. Power users alag karte hain: AI ko aisi briefing dete hain jaise ek naye smart colleague ko dete — files, context, limits, aur clear sawal.

Zaroori baat shuru mein:

Model stateless hai — usay khud kuch yaad nahi rehta, har baar sirf usi text se jawab deta hai jo iss waqt uske samne hai. Is liye almost har "advanced trick" ek hi cheez hai: sahi cheez andar daalo, ya galat cheez bahar rakho.

Zaroori Alfaz:

Pretrained knowledge = jo AI ne training mein parha, bina dekhe. Knowledge cutoff = wo date jahan training rukti hai. Web search = live pages fetch kar ke parhna. Deep research = kai minute mein poori report banana. Slop = achi lagti khaali baat. Rubric = check karne wali list. Sycophancy = aapko wahi bolna jo aap sunna chahte ho. Context window = wo poora text jo AI dekh sakta hai. System prompt = company ki pehle se rakhi rules. Memory = tool ka note. Context rot = lambi chat mein jawab kharab hona. Projects = ek jagah jahan files/rules save hon. Reasoning = AI apna kaam khud likhta hai jawab se pehle.

Kya Badla Hai 2022 Se Ab Tak

Badlaav:

Context window 1000 guna bara ho gaya. Reasoning asli ban gayi. Web search built-in ho gayi. Code chalana built-in ho gaya. Images/audio normal ban gaye. Tools ab aapko yaad rakhte hain. Desktop apps aur coding agents aa gaye.

Part 1: AI Cheezein Kaise Jaanta Hai

Idea 1 (Novice vs Power User):

Sawal same hota hai, briefing alag hoti hai. Novice: "kaunsi gaari behtar hai?" — generic jawab. Power user: spec sheets, quotes attach karta hai, "trade-offs batao, achi tarah socho." AI ek naya, bohat smart colleague hai jo pehle din join hua hai — motivated hai, aapke baare mein kuch nahi jaanta. Har naye chat mein zero se shuru hota hai. Briefing ke 4 hisse: files, goal, limits, exact sawal.

Idea 2 (Pretrained Knowledge):

AI ne duniya mein reh kar nahi seekha — sirf text parh kar seekha. Jo topic zyada likha gaya, usme AI strong hai. Jo kam likha gaya, usme weak hai. Strong: cooking, mashhoor movies. Sparse: kam maloom cheezein. Absent: private data, cutoff ke baad ki koi baat. Zaroori baat: typo fix karne ki zaroorat nahi. AI ne internet se galat baatein bhi seekhi hain.

Idea 3 (3 Tareeqe Jawab Dene Ke):

AI 3 tareeqon se jawab deta hai: Pretrained (yaad se, purani cheezon ke liye), Web search (live pages se, current cheezon ke liye), Deep research (kai minute mein bohat sources se poori report). "AI Google nahi hai" — Google se link milta hai, AI se pura analysis milta hai. Behtar web search ke liye 3 aadatein: sources naam batao, har claim ke baad source mango, "unverified" likhne ko kaho.

Part 2: AI Se Achi Tarah Baat Karna

Context Window ki 6 layers — sirf ye cheezein AI dekh sakta hai

Idea 4 (Context Hi Sab Kuch Hai):

Insaan ek waqt mein 4-7 cheezein yaad rakh sakta hai. AI hazaron lafz dekh sakta hai — lekin sirf jo aap ne diya hai. Context window mein 6 cheezein: System prompt, Tool descriptions, Aapka prompt, Chat history, Aapki files, Memory. Reading desk misaal: jo mez par hai, AI wahi parh sakta hai. Apni instructions daal sakte ho settings mein, lekin chhota rakho.

Context Rot aur Projects:

Lambi chat mein kai alag topics dalne se jawab kharab hota jata hai. Jab topic badle, nayi chat kholo. Memory = tool ka likha hua note jo har naye chat mein dobara daala jata hai, model ki yaad nahi. Projects: jab aap 2 dafa same files/context paste kar chuke ho, usay Project mein daal do — har naya chat wahan se khud parh lega.

Idea 5 (Reasoning, ya "Achi Tarah Socho"):

Modern AI khud thinking mode rakhta hai. 3 tareeqe on karne ke: plain zubaan mein "achi tarah socho" likho, thinking-mode switch use karo, ya tool khud on kar dega. Extended thinking matlab AI kai seconds/minutes tak socha ke jawab deta hai. Kab use na karo: chhote sawal, quick lookups — slow aur zyada mehnga hota hai.

Idea 6 (Sycophancy Aur Usay Theek Karna):

AI ne millions users se "thumbs up" dekh kar seekha — agree karna zyada thumbs up leta hai. Fix: neutral alfaz use karo. "kya X sahi hai?" ki jagah "X ko dono taraf se evaluate karo" likho. Rubric use karo: number force karo (1-10) — number vague tareef se behtar hota hai kyun ke compare/track kar sakte ho.

Brainstorm-Iterate Loop — options mango, feedback do, dobara, tabhi expand karo

Idea 7 (Brainstorm-Iterate Loop):

Ek hi cheez maangna average jawab deta hai. 6 steps: poora context do, 3-5 options mango (expand mat karwao), bilkul batao kya pasand aya kya nahi, feedback par naye options mango, dohrao, tabhi ek option ko poora likhwao. Outline mein ek lafz badalna poore article ki direction badal sakta hai — final draft mein ek lafz badalna sirf ek lafz badalta hai.

Part 3: Text Se Aage

Idea 8 (Multimodal — Images Aur Audio):

Image parhna: AI overall scene, bare shapes, whiteboard, handwriting parh sakta hai. Weak: fine detail, choti cheezein ginna. Image banana: Text AI se pehle image prompt likhwao, phir image tool mein paste karo — ye diffusion model hai, noise se shuru hota hai, ek dafa mein pura banta hai. Zabardast trick — diagrams: pehle Claude se SVG banwao, phir ChatGPT/Gemini se redraw karwao — 10-15 minute mein professional diagram. Audio: speak kar ke prompt de sakte ho, meeting recording daal kar summary mango.

Idea 9 (Ek Prompt Se Chhoti App Banana):

Sab 3 tools ek chhoti app "artifact/canvas" mein bana dete hain — edit, share, download ho sakti hai. 3 slots: Goal (kya karna hai), Input (user kya dega), Output (user kya dekhega). Kya kaam karta hai: chhoti games, timers, calculators. Kya mushkil hai: multiplayer, live language coaching.

Idea 10 (Data Analysis — AI Khud Code Chalata Hai):

Spreadsheet upload karo, sawal poocho — AI code likhta hai, chalata hai, result se jawab deta hai. Zaroori check: AI hamesha code nahi chalata, kabhi guess kar leta hai. 3 aadatein: seedha poocho "code likho aur chalao, dikhao", dekho jawab mein code block hai ya nahi, pehle checkable fact poocho (row count, column names).

Part 4: Safely Kaam Karna Aur Tools Chunna

Idea 11 (AI Desktop Apps Aur Permissions):

Ye apps (Cowork, OpenWork) aapki files ko access, edit kar sakti hain. Safe workflow (4 steps): Task batao → Plan mango (action nahi) → Plan parho, review karo → Tabhi approve karo. Zaroori khatra: Delete ki files recycle bin mein nahi jatin. Edit ki files ka koi history nahi hota. Sabse chhota permission do jo zaroori hai.

Idea 12 (Cost, Speed, Aur Kaunsa Model):

Cost order (sasta se mehnga): Text → Speech → Images → Video → Deep research (video text se ~16 guna mehnga). AI jagged hai — har model alag kaam mein acha hai, leader badalta rehta hai. 2 aadatein: same prompt 2-3 models mein try karo, sirf ek tool se shaadi mat karo. Model ladder: ek company ke andar fast/medium/heavy models hote hain — sahi rung chuno.

Idea 13 (Koi Expert Na Ho To):

Jab kisi kaam mein koi human expert judge available nahi hota, to alag alag companies ke models ek doosre ke jawab ko check karte hain — ye aapko best signal deta hai ke kaam kitna sahi hai. Har model ka jagged frontier alag hai, is liye ek model doosre ki galtiyan pakar leta hai jo khud us galti se anjaan hota.

End Summary (Aik Nazar Mein)

  • Power-user prompt = ek briefing, sirf sawal nahi
  • AI training se seekha hai — jo topic zyada likha gaya, usme strong, jo kam likha gaya, usme weak
  • 3 tareeqe: Pretrained (yaad se), Web search (live pages), Deep research (poori report)
  • Context window = 6 layers (system prompt, tools, aapka prompt, chat history, files, memory)
  • Thinking mode "achi tarah socho" bolne se on hota hai — hard sawalon ke liye
  • Sycophancy: AI agree karne ki taraf jhukta hai — neutral alfaz aur rubric use karo
  • Brainstorm-iterate loop: context → options → feedback → dobara → tabhi expand
  • Images/audio parhna aur banana alag skills hain
  • Ek prompt se chhoti app ban sakti hai (Goal, Input, Output)
  • Data analysis: AI code chalata hai, lekin confirm karo ke waqai chalaya
  • Desktop apps ko sirf zaroori chhota permission do, plan pehle mango
  • Har model alag kaam mein acha hai — kai models try karo, ek se shaadi mat karo
  • Koi expert na ho to, models ek doosre ko grade kar sakte hain — best signal
